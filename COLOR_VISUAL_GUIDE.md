## BUTTON COLOR SCHEMES

### Primary Button
**Light Mode:**
- **Background**: `linear-gradient(135deg, #2563eb 0%, #1e40af 100%)`
- **Text**: `#ffffff` (White)
- **Shadow**: `0 4px 12px rgba(37, 99, 235, 0.3)`
- **Hover**: `0 6px 16px rgba(37, 99, 235, 0.4)` + `translateY(-2px)`

**Dark Mode:**
- Same gradient
- Same text/shadow behavior

```
┌─────────────────────────┐
│ Primary Button (Normal) │ ← Blue Gradient: #2563eb → #1e40af
│ Subscribe               │
└─────────────────────────┘
   Shadow: subtle 4px blur

┌─────────────────────────┐
│ Primary Button (Hover)  │ ← Slightly elevated, stronger shadow
│ Subscribe               │
└─────────────────────────┘
   Shadow: stronger 6px blur
```

### Outline Button
**Light Mode:**
- **Background**: `#ffffff` (White)
- **Border**: `1.5px solid #d1d5db` (Gray)
- **Text**: `#475569` (Dark Gray)
- **Hover**: Border → `#2563eb`, Text → `#2563eb`

**Dark Mode:**
- **Background**: `#0f1724` (Dark card)
- **Border**: `1.5px solid #334155` (Dark border)
- **Text**: `#b0b9c6` (Light gray)
- **Hover**: Border → `#2563eb`, Text → `#2563eb`

```
Light Mode:
┌─────────────────────────┐
│ Outline Button          │ ← White bg, gray border
│ Learn More              │
└─────────────────────────┘

Dark Mode:
┌─────────────────────────┐
│ Outline Button          │ ← Dark bg, dark border
│ Learn More              │
└─────────────────────────┘
```

### Secondary Button
**Light Mode:**
- **Background**: `#f1f5f9` (Light blue-gray)
- **Text**: `#0f172a` (Dark text)
- **Hover**: Background lightens slightly

**Dark Mode:**
- **Background**: `#1e293b` (Dark slate)
- **Text**: `#e6eef8` (Light text)
- **Hover**: Background lightens slightly

### All Color Combinations Meet WCAG AA (4.5:1 contrast minimum):
- ✅ Dark text (#0f172a) on light backgrounds
- ✅ Light text (#e6eef8) on dark backgrounds
