## 🔍 KEY FEATURES

### CSS Variables System
```css
:root {
  --primary: #2563eb;
  --primary-light: #1e40af;
  --accent: #0ea5a4;
  --bg: #f5f7fb;
  --card: #ffffff;
  --text: #0f172a;
  --success: #16a34a;
  --warning: #f59e0b;
  --danger: #dc2626;
}
```

### Dark Mode Support
```css
:root[data-theme="dark"] {
  --bg: #0b1220;
  --card: #0f1724;
  --text: #e6eef8;
  /* All colors automatically adjust */
}
```

### Button Styling
```css
.btn-primary {
  background: linear-gradient(135deg, #2563eb 0%, #1e40af 100%);
  box-shadow: 0 4px 12px rgba(37, 99, 235, 0.3);
}
```

```css

.my-element {
  color: var(--text);
  background: var(--card);
  border: 1px solid var(--border-primary);
}

/* Or use direct values */
.my-button {
  background: #2563eb;
  color: #ffffff;
```
