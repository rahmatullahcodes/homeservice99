### Mobile (320px - 479px)
```
Single Column Layout
Cards: 100% width
Image: 140px height
Layout: Horizontal (image left, content right)
Gap: 12px
Padding: 10px
Button: Compact (9px padding)
Font: Smaller (12-13px)

```
Two Column Layout

## User Journey

### Step 1: Home Page Load
```
User sees:
- Hero section with search
- Category selection
- "Popular Services" heading appears
```

### Step 2: Service Card Display
```
Cards render in:
- Grid layout (3-4 on desktop)
- Smooth fade-in animation
- Professional appearance
```

### Step 3: User Hovers
```
Card animation:
- Lifts up smoothly
- Shadow enhances
- Border changes color
- Title becomes more prominent
```

### Step 4: User Clicks "Book Now"
```
Navigation:
- Navigate to /services
- Category pre-selected (e.g., "Cleaning")
- Services page filters by category
```
